# Isolated device preflight
Synthetic assemblies only, no Celeste or FMOD files. Build both original and patched fixture assemblies and independent mock module on desktop. Run identical ProbeChecks on desktop and tvOS. The mock module has a real assembly dependency, adds two typed hooks through an ordinary event, changes argument/return values, and removes both hooks. This is inspired by the external static hook architecture recorded in EXTERNAL_REFERENCES.md, but is an independent minimal fixture, not a port of its production hook backend. No native detours, runtime game patching, or real mod download. Simple DynamicMethod is checked only when runtime advertises support. The isolated host checks the runtime test bundle ID and rejects game payloads; no save APIs called. Package unsigned artifact using existing Windows packager with --probe and native library only. Do not install over production v10. A PASS does not establish Everest startup or arbitrary mod compatibility.
